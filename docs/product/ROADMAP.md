# Roadmap

## Fase 0 — Fundação
- [x] Definir visão, princípios e limites iniciais.
- [x] Documentar escopo conservador do MVP.
- [ ] Validar jornada com a psicóloga piloto.
- [ ] Confirmar informações públicas, contato, retenção e operação.

## Fase 1 — Presença profissional
- [ ] Configurar Vue 3 + TypeScript + Vite.
- [ ] Construir landing page e perfil profissional.
- [ ] Revisão de conteúdo pela profissional.
- [ ] Acessibilidade, SEO e testes visuais básicos.

## Fase 2 — Solicitações administrativas
- [ ] Definir modelo mínimo de dados e política de retenção.
- [ ] Configurar Supabase Auth e RLS após revisão de segurança.
- [ ] Formulário mínimo e painel protegido.
- [ ] Testes de autorização, exclusão e fluxo completo.

## Fase 3 — Piloto
- [ ] Testar com dados fictícios em homologação.
- [ ] Piloto controlado com consentimento e aviso de privacidade revisados.
- [ ] Medir clareza, tempo de resposta e facilidade de uso sem coletar dados clínicos.
- [ ] Priorizar melhorias com base no uso.

## Fase 4 — Expansão (decisão futura)
- [ ] Avaliar cadastro de outros profissionais.
- [ ] Avaliar pagamentos e agenda integrada.
- [ ] Avaliar videoatendimento por fornecedor adequado.
- [ ] Avaliar iniciativas sociais e bolsas.
- [ ] Aplicativo somente após validação de demanda.

Cada fase depende de evidência e revisão. Não iniciar fases futuras apenas porque estão listadas.
